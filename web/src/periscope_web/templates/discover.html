Find my services

Knock on the addresses on your network and see which of them answer like something periscope can talk to, then fill that service's settings in for you. A scan only ever runs when you press the button on this page — periscope never goes looking on its own, and it only reads the public version endpoint each product offers, without signing in to anything.

Or read it out of a file

For anything the scan cannot reach — a service on a different network, or one behind Docker with no published port. A compose file or an *arr config.xml often carries the API key too, which saves you copying it. Keys read this way are written straight to your settings; this page will only ever tell you that one was found, never show it.

The folder is read on the machine periscope runs on. Point it at the parent — /opt/appdata when your configs live in /opt/appdata/sonarr/config.xml.
